プライバシーポリシー

「oyasumi-analytics」（以下「本ツール」）は、YouTube チャンネル「おやすみ怪談」の運営者（以下「運営者」）が、自分のチャンネルの統計を読み取るために使う内部ツールです。本ツールが扱う情報の取り扱いを次のとおり定めます。

1. 取得する情報

本ツールは、運営者本人の Google アカウントによる許可（OAuth）のもと、YouTube Analytics API を通じて、運営者本人の YouTube チャンネルの統計情報（視聴回数、エンゲージメント視聴、視聴者維持率、高評価数、コメント数、共有数、チャンネル登録者の増減、平均視聴時間など）を取得します。視聴者個人を特定できる情報は取得しません。

2. 利用目的

取得した統計情報は、運営者が動画の作り方を改善するための分析にのみ使います。広告配信、第三者への提供、販売には使いません。

3. 保存と管理

取得した統計情報と Google から発行された認証トークンは、運営者が管理するコンピュータにのみ保存します。第三者のサーバーには送信しません。

4. 第三者への提供

取得した情報を第三者に提供・共有・開示することはありません（法令に基づく場合を除く）。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

6. 許可の取り消し

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも本ツールの許可を取り消すことができます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネル「おやすみ怪談」の概要欄に記載の連絡先までお願いします。

8. 改定

本ポリシーは必要に応じて改定します。改定した場合は本ページで公開します。
