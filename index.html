おやすみ怪談 制作ツール（oyasumi-analytics）

このページは、YouTube チャンネル「おやすみ怪談」の運営者が、自分のチャンネルの YouTube アナリティクスの数字（視聴回数・視聴者維持率など）を読むために使っている内部ツール「oyasumi-analytics」の案内です。

何をするツールか

  • 運営者本人の Google アカウントで許可を受け、運営者本人のチャンネルの統計だけを YouTube Analytics API から読み取ります。
  • 読み取った数字は、次の動画の作り方を決めるための分析にだけ使います。
  • 利用者は運営者本人のみで、一般の方に提供するサービスではありません。
